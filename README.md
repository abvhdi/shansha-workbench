# 珊莎工作台

**把事情记下来，接着做。**

DeepSeek Harness 的 Windows 本地工作台插件，把待办、资料、关联会话和业务数据放在一起。当前测试版 **0.1.83**。

## 安装

### 在 Harness 中添加插件源

在支持自定义插件源的 Harness 插件市场中添加以下索引地址，再搜索「珊莎工作台」或 `shansha-workbench`：

```text
https://raw.githubusercontent.com/abvhdi/shansha-workbench/main/market.json
```

这是本项目的自定义插件源，不代表已收录到 Harness 默认/官方列表。索引使用固定 Git 提交安装，GitHub 的源码、标签与安装包保持同一版本。

### 下载安装包

到 [最新发布页](https://github.com/abvhdi/shansha-workbench/releases/latest) 下载 `shansha-workbench-0.1.83.tgz`，通过 Harness 插件管理器升级；也可将安装包和 [INSTALL-AI.md](INSTALL-AI.md) 交给有本机操作能力的 Agent，要求保留现有数据后安装。

升级后请完整退出 Harness（包括托盘）再打开。已核对接口：`0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.5`、`0.2.2-rc.1`；其他版本需另核对。

## 可以做什么

- **待办与随手记**：统一输入，待办清单、步骤、项目、日历提醒，按需关联已有会话。
- **Agent 协作**：读取关联待办、材料和业务表，提出数据修改，确认后执行；工作协作入口用于统筹。
- **文件工坊**：本地资料集中查找、打开和管理，关联会话的文件产出回到工作台。
- **业务数据库**：导入 Excel/CSV、新建表格、直接改单元格、同表计算列，按需建立客户、订单、合同、发票等表之间的关联。
- **表格整理**：一层自建分组、拖动归组和排序、双击重命名、拖动列标题换位置，顺序保存在本机。
- **关联与附件**：关联记录按名称显示；取消关联保留名称为普通文字；每条记录可添加本地附件。

## 数据与限制

待办和材料元数据保存在 Harness 本地浏览器存储中；业务 SQLite 在文档目录「珊莎数据库」，文件副本在工作台的本地文件目录。业务表初始可为空，需要自行新建或导入；不会在安装时生成虚构客户和订单。

- 面向 Windows；本地文件打开助手随包提供。
- 单个数据库附件最多 50 MB；图片/PDF/Office 交给宿主已有文件工具读取，不能保证任何格式都能识别。
- 计算列目前支持同表数字四则运算，不是完整 Excel 公式，也不自动做跨表汇总。
- 业务数据库与文件需要单独备份；原待办 JSON 备份不等于全部业务数据备份。
- 手机网页同步是可选实验功能，需要额外配置云端，不是安装后即用的跨端同步。
- 188 项自动测试及隔离 React/SQLite 页面流程已验证；真实模型效果、其他电脑与宿主版本仍需实际试用。

## 开发

仓库包含源码、测试和构建产物。使用 Node.js 运行：

```sh
node --test test/*.test.cjs
node build.cjs
```

部分宿主兼容测试依赖本机 Harness 安装目录；Windows 原生文件打开助手的源码位于 `src/native-open.cs`。第三方组件与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。历史改动见 [CHANGELOG.md](CHANGELOG.md)。
