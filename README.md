# 珊莎工作台

**待办、文件、对话，都在一起。**

这是 DeepSeek Harness 的本地插件。记录待办、整理项目、添加资料，并关联会话继续处理工作。

## 下载与安装

1. 先安装 DeepSeek Harness。
2. 到 [0.1.1 测试版下载页](https://github.com/abvhdi/shansha-workbench/releases/tag/v0.1.1) 下载 `shansha-workbench-0.1.1.tgz` 和 `INSTALL-AI.md`。
3. 把安装包和说明交给有本机操作能力的 AI，说：

> 请按 INSTALL-AI.md 帮我升级珊莎工作台，保留现有待办、资料和会话关联，安装后检查结果。

完全退出并重启 Harness。安装与验证步骤见 [AI 安装说明](INSTALL-AI.md)。

## 本次更新

- 到期待办整行显示浅暖色，“已到期”更明显；点击“延后”选择下一次提醒时间，保留原重复规则。
- 新增“自定义顺序”视图：拖动排列待办，顺序自动保存；有会话的待办可直接进入原会话。默认列表、项目和日历保留。
- 本地待办文件夹里的新增和修改自动读取；移入项目时迁移整个待办文件夹。同名冲突保留不同内容，相同旧副本确认后清理。
- 待办材料和文件工坊支持右键重命名、复制、打开方式和删除。
- 打开已保存文件不再等待整批同步。Windows 打开助手随包分发；无默认程序时进入“打开方式”。

## 已有功能

待办、步骤清单、项目与日历、周期提醒、文件工坊和搜索。待办可关联 Harness 会话；AI 通过工具读取待办与材料，并按用户明确要求修改备注、标题和步骤。会话把文件写入工具返回的产出目录后，插件自动收取。

## 测试版与限制

版本 **0.1.1**，目前面向 Windows 桌面版；已核对宿主 `0.2.0-rc.2`。尚未完成另一台电脑的安装验证，其他版本需核对接口。

- 本地文件超过 50 MB 时只保存引用，不加载整份文件进浏览器；可打开、复制和重命名。大文件不支持直接作为会话附件或打包进 JSON 备份，请使用本地与自动备份文件夹。
- 拖入后是否删除原件需要宿主提供真实原路径；拿不到路径时保留原件。可记住选择，并在“文件保存位置”里重设。
- 提醒为 Harness 运行时的应用内提醒，关闭程序不会产生系统通知。
- 文件工坊目前主要按文件名检索；跨 App 原生拖出、跨设备同步暂未实现。
- 代码测试与独立浏览器验证通过，不代表所有播放器和真实宿主场景均已验证。
