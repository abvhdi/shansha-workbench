# 珊莎工作台


**待办、文件、对话，都在一起。**


这是 DeepSeek Harness 的本地插件。你可以记录待办、整理项目、添加文件，并关联会话继续处理工作。


## 下载与安装


1. 先安装 DeepSeek Harness。
2. 到 [测试版下载页](https://github.com/abvhdi/shansha-workbench/releases/tag/v0.1.0) 下载 `shansha-workbench-0.1.0.tgz` 和 `INSTALL-AI.md`。
3. 把安装包和说明交给有本机操作能力的 AI，说：


> 请按 INSTALL-AI.md 帮我安装珊莎工作台，保留现有数据，并检查安装结果。


安装后完全退出并重启 Harness。具体检查步骤见 [AI 安装说明](INSTALL-AI.md)。


## 已有功能


- 待办、步骤清单、项目与日历视图、周期提醒。
- 文件工坊：搜索材料、打开文件、复制文件及本地保存。
- 待办关联会话，AI 可读取材料并按明确要求修改待办。
- 会话将文件写入指定产出目录后，自动收进关联待办。
- 自动备份、导出与恢复。


## 测试版说明


本版为 0.1.0 测试版，已核对的 Harness 版本为 0.2.0-rc.2。尚未在另一台电脑完成安装验证，其他宿主版本需要检查兼容性。


当前拖入材料保存副本，不会删除原文件。直接往本地文件夹放文件后自动收取、跨 App 拖出文件暂未实现。
