# 珊莎工作台

**把事情记下来，接着做。**

DeepSeek Harness 的本地工作台插件，把待办、资料、关联会话和业务数据放在一起。当前测试版 **0.1.112**，主要面向 Windows。

## 安装与升级

在支持自定义插件源的 Harness 插件市场中添加以下地址，搜索「珊莎工作台」或 `shansha-workbench`：

```text
https://raw.githubusercontent.com/abvhdi/shansha-workbench/main/market.json
```

这是项目自定义插件源，不代表已收录到 Harness 官方默认列表。也可填写固定版本仓库地址：

```text
https://github.com/abvhdi/shansha-workbench.git#v0.1.112
```

仓库安装需要本机 Git 且能连接 GitHub。遇到 Git 缺失或仓库连接超时，可到 [最新发布页](https://github.com/abvhdi/shansha-workbench/releases/latest) 下载 `shansha-workbench-0.1.112.tgz`，交给 Harness 插件管理器安装；安装包不要求本地编译。可将安装包与 [INSTALL-AI.md](INSTALL-AI.md) 交给有本机操作能力的 Agent 安装。

升级请保留原有数据，**完整退出 Harness（包括托盘）再打开**。已核对宿主接口版本：`0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.5`、`0.2.2-rc.1`；其他版本需另核对。

## 功能

- **待办与随手记**：统一输入、步骤清单、项目归类、日历提醒，按需关联已有会话。
- **工作协作**：读取待办、材料和业务表，在回答下方打开相关待办或数据表；数据库修改须确认。
- **文件**：本地资料集中查找、打开和管理，会话文件产出回到工作台。文件页按项目展示，搜索支持名称、项目、待办和类型关键词。
- **业务数据库**：Excel/CSV 导入、单元格直接编辑、同表计算列、客户/订单/合同/发票等表的关联、记录附件、分组和拖动排序。
- **模板**：上传文件或从已有文件保存独立模板副本，支持会话查询与选择。

## 模板填写流程

在「文件 → 模板」右击模板，选择「配置填写项」。当前支持 `.docx` 和 `.xlsx` 的文字与表格结构识别：

1. 点击「AI 识别填写位置」，使用 Harness 当前选择的模型提出建议；无需预先写占位符，也保留 `{{客户名称}}` 等占位符的识别方式。
2. 左侧预览模板、右侧核对规则。填写位置有编号和黄色标记，点击可相互定位。
3. Excel 右击单元格添加填写项；Word 选中文字后右击设为填写项，或在文字间/空白表格右击插入标记。
4. 修改名称、类型、必填要求及取值来源后保存规则。位置或设置错误会就地标红，保存时定位到对应项与控件。
5. 在会话中选择本次模板，让助手依据数据库或待办资料整理填写草稿；可直接修改会话下方的填写卡片，确认后让助手继续生成文件。

普通查询、读取和“继续”不会重置当前文件的模板确认；明确另做一份或重新选择才开启新请求。切换合同模板后，本次读取不再返回旧报价草稿。

AI 识别结果须人工核对。预览保留文字和表格结构，不保证 Word 复杂分页、字体、图片等布局完全还原。配置只保存规则和位置，不直接改写原模板；生成文件仍由宿主 Agent 的文件工具执行，不保证任意复杂文档都能自动准确填写，也不会自动完成正式数据库写入。

AI 识别会将受限的模板文字结构发送给当前所选模型，使用对应模型服务及其计费规则；扫描图片/PDF 的 OCR 不在本功能范围内。

## 本地数据与限制

待办和材料元数据保存在 Harness 本地浏览器存储；业务 SQLite 位于文档目录「珊莎数据库」。模板文件、填写规则与草稿保存在文档目录「珊莎模板」，请另行备份；待办 JSON 备份不等于全部业务数据、模板或文件的完整备份。

- 单个模板最多 20 MB；模板识别与预览有范围上限，大文档会提示部分读取。
- 本地文件打开助手主要面向 Windows。macOS 的 SQLite 路径选择已修复，但未在真实 Mac 全面验证。
- 计算列支持同表数字四则运算，不是完整 Excel 公式，也不自动做跨表汇总。
- 手机网页同步是需额外配置的可选实验功能，不是安装即用的跨端同步。
- 215 项自动测试通过，模板卡片与配置交互经过隔离浏览器验证；不同模型、真实宿主和其他电脑仍需试用。

## 开发

仓库保留源码、测试和构建产物，运行：

```sh
node --test test/*.test.cjs
node build.cjs
```

部分宿主兼容测试需要本机 Harness 目录；Windows 文件打开助手源码为 `src/native-open.cs`。许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，历史改动见 [CHANGELOG.md](CHANGELOG.md)。
